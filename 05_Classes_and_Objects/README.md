# Classes and Objects

![Overview](images/overview.svg)

## Description

This folder is dedicated to understanding object-oriented programming (OOP) fundamentals in Java, specifically focusing on classes and objects. Classes are blueprints or templates for creating objects, while objects are instances of classes that contain data (attributes) and behavior (methods).

This module introduces the core concepts of OOP, including how to define classes, create objects from those classes, and understand the relationship between classes and objects. Students will learn about class structure, object instantiation, and how objects interact with each other in a Java program.

The concepts covered here form the foundation for more advanced OOP topics like inheritance, polymorphism, and encapsulation, which are explored in subsequent modules.

## বিবরণ

এই ফোল্ডারটি Java-তে object-oriented programming (OOP)-এর মৌলিক বিষয়সমূহ বোঝার জন্য নিবেদিত, বিশেষভাবে classes এবং objects-এর উপর focus করে। Classes হল blueprints বা templates যা objects তৈরি করার জন্য ব্যবহৃত হয়, অন্যদিকে objects হল classes-এর instances যা data (attributes) এবং behavior (methods) ধারণ করে।

এই মডিউলটি OOP-এর core concepts-এর সাথে পরিচয় করায়, যার মধ্যে রয়েছে কীভাবে classes define করতে হয়, সেই classes থেকে objects তৈরি করতে হয়, এবং classes এবং objects-এর মধ্যে সম্পর্ক বুঝতে হয়। শিক্ষার্থীরা class structure, object instantiation, এবং কীভাবে objects একটি Java program-এ একে অপরের সাথে interact করে তা শিখবে।

এখানে covered করা concepts-গুলো আরও advanced OOP topics যেমন inheritance, polymorphism, এবং encapsulation-এর জন্য ভিত্তি তৈরি করে, যা পরবর্তী মডিউলগুলিতে আলোচনা করা হয়। এই মডিউলটি Java-এর object-oriented paradigm-এর একটি গুরুত্বপূর্ণ অংশ এবং এটি শিক্ষার্থীদের real-world programming problems সমাধানের জন্য প্রয়োজনীয় skills প্রদান করে।
